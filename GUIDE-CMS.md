# Guide simple : modifier le site sans coder

Ce guide est pour l'équipe de l'Association Maison Verte d'Haïti — aucune
connaissance en informatique n'est nécessaire.

## 1. Se connecter

1. Va sur **https://maisonvertehaiti.org/admin/**
2. Connecte-toi avec l'email et le mot de passe que tu as créés (via l'email d'invitation reçu).
3. Tu arrives sur le tableau de bord du CMS : une liste de catégories à gauche.

## 2. Où trouver quoi

| Je veux modifier… | Je clique sur… |
|---|---|
| Le menu en haut du site | ⚙️ Réglages du site → Menu de navigation |
| L'email, l'adresse, Facebook, etc. | ⚙️ Réglages du site → Coordonnées & réseaux sociaux |
| Le texte d'accueil et le mot du coordonnateur | ⚙️ Réglages du site → Page d'accueil |
| Les options pour faire un don | ⚙️ Réglages du site → Section "Faire un don" |
| Ajouter/modifier une actualité | 📰 Actualités |
| Ajouter/modifier une édition du festival Cinécolo | 🎬 Éditions du festival Cinécolo |
| Ajouter/modifier un projet (Cinécolo, Karibiodiv, etc.) | 📁 Nos projets |
| Ajouter/retirer une photo de la galerie | 🖼️ Galerie photo |
| Les images qui défilent en haut de l'accueil | 🎞️ Bandeau défilant (accueil) |
| Le texte "À propos" de l'association | 🌿 À propos de Maison Verte |

## 3. Ajouter un nouvel élément (ex : une actualité)

1. Clique sur la catégorie (ex : "📰 Actualités").
2. Clique sur le bouton **"New Post"** (ou "+ Nouveau") en haut à droite.
3. Remplis les champs (titre, image, texte…).
4. Pour ajouter une image : clique sur le champ image, puis **"Choose an image"**,
   puis **"Upload"** pour envoyer une photo depuis ton ordinateur ou ton téléphone.
5. En bas à droite, clique sur **"Publish"** (Publier).

C'est tout — le site se met à jour automatiquement en 1 à 2 minutes.

## 4. Modifier un élément existant

1. Clique sur la catégorie, puis sur l'élément à modifier dans la liste.
2. Change ce que tu veux.
3. Clique sur **"Publish"** (ou "Save" puis "Publish").

## 5. Cacher un élément sans le supprimer

Beaucoup d'éléments (actualités, projets, photos, éditions) ont une case à
cocher **"Afficher sur le site ?"**. Décoche-la et publie : l'élément disparaît
du site public, mais reste enregistré si tu veux le remettre plus tard.

## 6. Supprimer définitivement un élément

Ouvre l'élément, puis en haut à droite, clique sur le menu **"..."** (ou
l'icône de corbeille) → **Delete entry**.

## 7. "Ordre d'affichage"

Certaines sections (projets, éditions, galerie, bandeau défilant) ont un champ
**"Ordre d'affichage"**. Plus le chiffre est petit, plus l'élément apparaît en
premier (1 = en premier, 2 = en deuxième, etc.).

## ⚠️ La section "Pages avancées (HTML)"

Cette section permet de modifier les pages très détaillées du projet Cinécolo
(archives par année, galerie du festival, presse). Le contenu y est affiché en
code HTML brut — à modifier uniquement si tu es à l'aise avec ça, ou avec l'aide
d'une personne technique. Pour tout le reste (actualités, projets, dons,
galerie principale, menu…), les formulaires simples des autres sections suffisent.

## Besoin d'aide ?

Si quelque chose ne s'affiche pas comme prévu après une modification, attends
1 à 2 minutes (le temps que le site se reconstruise) et rafraîchis la page. Si
le problème persiste, contacte la personne technique responsable du site.
